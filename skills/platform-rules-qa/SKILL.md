# 平台规则问答

评价运营相关的平台规则问答：给条款、给出处、给下一步动作。证据不全的申诉案件劝退不提交。

**规则库检索由 `scripts/rules_qa.py` 完成（召回阈值 3 分、返回 Top 3），条款召回结果以脚本输出为准。**

## 能力描述

1. **内置规则库 8 类条款**：恶意差评申诉（订单记录/聊天记录/物流凭证三件套，成功率约 40-60%）、评价删除与修改（天猫 30 天内买家可改一次）、诱导好评（返现/返红包违反《反不正当竞争法》第 8 条）、刷单炒信（第 8 条 + 《电子商务法》第 17 条）、回复率 100% 基准（30-80 字/条、差评 2 小时响应）、差评骚扰认定（严重违规一次扣 48 分）、退款时效（48 小时须响应）、评价展示权重（追评 > 首评）
2. **检索规则**：命中关键词 ×2 / 命中标题 ×3 / 命中正文 ×1，总分 ≥ 3 召回，Top 3
3. **证据把关**：申诉类问题自动附证据包核对清单，任一关键证据缺失 → 不提交
4. **知识缺口机制**：检索不召回的明确说未覆盖，指向官方规则中心，不编条款

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供平台 + 问题（申诉类附订单状态与证据现状）
3. 得到条款依据 + 证据核对 + 下一步动作

### 方式二：带脚本（规则库检索 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/rules_qa.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/rules_qa.py --demo
```

产物：

| 文件 | 内容 |
|---|---|
| `out/规则检索结果.xlsx` | 检索问答（未覆盖标红）/ 命中条款明细 / 申诉证据包清单 |
| `out/rules_qa.json` | 机器可读结果 |

**分工**：脚本做关键词打分检索；模型做条款适用判断与案件定性。

## 边界（不做的事）

- ❌ 不编造条款编号、扣分分值、罚款金额；知识库没有的明确说没有
- ❌ 不承诺申诉结果、不承诺删差评——判定权在平台
- ❌ 不提供规避处罚的方法（换号、刷单冲淡差评、谐音绕审核）
- ❌ 不建议任何利诱改评措辞；平台规则以官方最新公示为准

## 调用示例

**输入**（`examples/input.json`）：3 个问题——恶意差评申诉证据、好评返现处罚、花钱删差评可行性。

**输出**（脚本实跑，退出码 0）：召回 3 个、知识缺口 0 个。Q1 → R01 恶意差评申诉（附证据包三件套）；Q2 → R03 诱导好评（反法第 8 条）；Q3 → R02 评价删除规则（商家无删评权限，付费删评属违规宣称）。产物两件：Excel + JSON。

- 本技能输出为 **AI 辅助生成内容**，不构成法律意见，平台规则以官方最新公示为准
- 涉及封店、大额处罚、法律纠纷的案件提示商家走法定申诉/复议渠道
