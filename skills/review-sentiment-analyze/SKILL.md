# 评价情感分析

把一批评价变成「今天先处理谁」的分级清单：五级情感、P0-P2 处置优先级、四维标签归因。

**星级映射与词频统计由 `scripts/sentiment_analyze.py` 计算，数值以脚本输出为准，不要自己算。**

## 元信息

| 字段 | 值 |
|------|-----|
| ID | `de_ecom_03_sk01` |
| 类型 | **`atomic`（原子技能）** |
| 所属员工 | 评价运营官 |
| 能力族 | 检测判断型 · 情感分级 |
| 复杂度 | `M` |
| 阶段 | `P0` |
| 复用度 | ★★★★★（与 weekly-review-flow / review-stream-monitor-flow 共用） |
| 资产形态 | 纯提示词 + Python 脚本（无模型调用、无 API Key） |

## 能力描述

1. **五级情感判定**：星 1-2 强负 / 星 3 负面 / 无文字中性 / 星 4 正面 / 星 5 带图（或文字 ≥ 15 字）强正
2. **处置优先级**：带图差评 = P0（2 小时，转化影响最大）＞ 强负 P1（12 小时）＞ 负面 P2（24 小时）；追评差评自动升级一级
3. **四维标签归因**：口味/质量、服务、物流、性价比词频统计（追评权重 ×2），Top 负面标签 = 下周改进项
4. **健康度对照**：好评率 ≥ 95%、差评率 > 3% 专项治理、涉诉风险词（12315/过敏/腹泻）预警
5. **误判复核（模型职责）**：反讽识别、默认好评与刷评剔除、图文不符判断

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shop` | string | ✅ | 店铺名 |
| `platform` | string | ✅ | 平台（天猫/淘宝/京东/拼多多/抖音） |
| `period` | string | ⬜ | 统计周期，如 2026-09-22 ~ 2026-09-28 |

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `summary` | object | 情感分布 / 好评率 / 差评率 / 健康度判定 |
| `detail` | array | 分级明细（优先级/时限/标签/涉诉词） |
| `tag_freq` | object | 负面四维标签加权词频（追评 ×2） |
| 产物 | 文件 | `out/评价情感分析.xlsx`、`out/情感分布.png`、`out/负面标签Top.png`、`out/sentiment.json` |

## 使用步骤

### 方式一：纯提示词（最快）

1. 打开你的 AI 工具（Coze / WorkBuddy / Dify / Claude / ChatGPT…）
2. 把 `prompt.txt` 全文粘贴为系统提示词
3. 提供评价列表（星级/文字/是否带图/是否追评）
4. 得到五级分布 + 处置分级清单

### 方式二：带脚本（词表精确扫描 + 产出 Excel）

```bash
python3 <SKILL_DIR>/scripts/sentiment_analyze.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/sentiment_analyze.py --demo        # 无输入也能看效果
```

产物：

| 文件 | 内容 |
|---|---|
| `out/评价情感分析.xlsx` | 分级明细（P0 标红）/ 标签词频 / 健康度对照 / 汇总 |
| `out/情感分布.png` | 五级情感占比饼图 |
| `out/负面标签Top.png` | 负面标签频次柱状图 |
| `out/sentiment.json` | 机器可读结果，供工作流读取 |

**分工**：脚本做星级映射与词表词频（不漏、不猜）；模型做反讽/刷评复核与处置建议。

## 边界（不做的事）

- ❌ 不编造评价或分布数据；缺字段列清单让用户补
- ❌ 不建议删差评、屏蔽差评或诱导改评（好评返现/返红包改评价均违规）
- ❌ 不替商家私下联系买家纠缠撤评；恶意差评走平台申诉通道
- ❌ 反讽/水军判定只给「疑似」标注，不做移除承诺，最终以平台判定为准

## 调用示例

**输入**（`examples/input.json`）：川味鲜食品旗舰店（天猫），2026-09-22 ~ 09-28 共 20 条评价（7 条 1-2 星、3 条 3 星、10 条 4-5 星，含 4 条带图差评、4 条追评）。

**输出**（脚本实跑，退出码 0）：

| 指标 | 实测 | 判定 |
|---|---|---|
| 好评率 | 50.0% | 低于基准 95%，须提升 |
| 差评率(1-2星) | 35.0% | 超过 3%，须专项治理 |
| P0 带图差评 | 4 条 | 2 小时内响应 |

负面标签 Top：口味/质量、物流、服务（追评 ×2 加权）。产物四件：Excel 分级明细、情感分布饼图、负面标签柱状图、机器可读 JSON。
