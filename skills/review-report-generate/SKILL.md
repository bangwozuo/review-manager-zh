# 复盘报告生成

把一周评价数据变成周会可直接过的复盘报告：结论先行、根因连业务动作、改进项带数字目标。

**指标计算与 Word/Excel 产物由 `scripts/report_gen.py` 完成，数值以脚本输出为准，不要自己算。**

| 字段 | 值 |
|------|-----|
| ID | `de_ecom_03_sk05` |
| 类型 | **`atomic`（原子技能）** |

## 能力描述

1. **固定六段结构**：核心结论 → 评分走势 → 指标对照 → 根因分布 → 回复情况 → 下周改进 3 项；缺数据段位标「数据缺失」，不编造
2. **健康度基准对照**：评分 ≥ 4.7、好评率 ≥ 95%、差评率 ≤ 3%（>3% 专项治理）、回复率 100%（30-80 字/条）、差评响应 ≤ 2 小时、一般评价 ≤ 24 小时
3. **对比归因方法**：先归一成差评率再对比（量级变化不算）；变化 ≤ 2 个百分点判噪声不下结论；大促后 48 小时差评冲高标注「大促回吐」；连续 3 天同向下滑才算趋势
4. **改进项硬约束**：根因 Top 3 每项带数字目标 + 责任人 + 完成时点，拒绝「加强品控」空话

## 输入规格

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `shop` / `platform` / `period` | string | ✅ | 店铺 / 平台 / 周期 |
| `this_week` | object | ✅ | {avg_score, total_reviews, good_rate, bad_rate, reply_rate, reply_hours_bad, reply_hours_norm} |
| `last_week` | object | ⬜ | 同结构；缺失则只报本周不对比 |
| `score_trend` | array | ⬜ | 近 7 天评分序列（生成走势图） |
| `root_causes` | array | ⬜ | [{cause, count}]，来自差评根因分类 |

## 输出规格

| 字段 | 类型 | 说明 |
|------|------|------|
| `summary` | object | 评分判定 / 首要根因 / 基准表 |
| `metrics` | array | 指标对照（达标/未达标） |
| `improves` | array | 下周改进 3 项 |
| 产物 | 文件 | `out/评价周报.docx`、`out/评价周报数据.xlsx`、`out/评分走势.png`、`out/report.json` |

## 使用步骤

### 方式一：纯提示词（最快）

1. 把 `prompt.txt` 全文粘贴为系统提示词
2. 提供本周/上周指标与根因分布
3. 得到摘要版周报（结论 + 对照表 + 改进项）

### 方式二：带脚本（Word 周报端到端）

```bash
python3 <SKILL_DIR>/scripts/report_gen.py --input input.json --outdir out
python3 <SKILL_DIR>/scripts/report_gen.py --demo
```

产物：

| 文件 | 内容 |
|---|---|
| `out/评价周报.docx` | 六段式周报（含走势图内嵌） |
| `out/评价周报数据.xlsx` | 指标对照（未达标标红）/ 根因分布 / 改进项 |
| `out/评分走势.png` | 7 天评分折线图 |
| `out/report.json` | 机器可读结果 |

## 边界（不做的事）

- ❌ 不把条数当比率对比；变化 ≤ 2 个百分点不下结论
- ❌ 不写无数字目标的改进项；不写与数据脱节的「整体向好」
- ❌ 数据缺失标「数据缺失」并列缺口清单，不用估算值填充
- ❌ 引用评价内容须脱敏，不带买家个人信息

## 调用示例

**输入**（`examples/input.json`）：悦己家居旗舰店（京东），本周评分 4.62（上周 4.68），差评率 4.6%，回复率 94%，根因分布物流 9 条/描述不符 4 条/工艺 2 条/服务 1 条。

**输出**（脚本实跑，退出码 0）：核心结论「本周评分 4.62，低于 4.7 达标线，须专项治理；首要根因物流占 56%」。指标对照 6 项中评分/好评率/差评率/回复率/差评响应 5 项未达标。下周改进 3 项：物流（发货 P90 ≤ 48h）、描述不符（详情页逐项修正）、工艺（破损率 < 0.5%）。产物四件：Word 周报、Excel 数据、走势图、JSON。
