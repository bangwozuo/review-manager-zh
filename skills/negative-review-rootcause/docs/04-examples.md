# 使用示例

## 示例 1：质量安全类触发当日处理

**输入**：`{"star": 1, "text": "芒果烂了三个，箱子里一股酒味，都变质了", "has_image": true}`。

**输出**：归因「质量问题(安全)」（规则树最高优先级）；质量安全占比 > 10% 时整批告警「当日下架留证批次自查，勿拖到周会」。

## 示例 2：连带表述拆主次根因

**输入**：`{"star": 3, "text": "物流太慢，到手都不新鲜了", "is_followup": true}`。

**输出**：主根因「物流问题」（最先触发），次标签涉及质量；追评权重 ×2 计入。模型复核时补全因果链：物流时效 → 生鲜变质，治理动作双线（发货时效 + 包装冰袋）。

## 示例 3：期望差不误伤品控

**输入**：`{"star": 3, "text": "口味偏甜，不合我口味"}`。

**输出**：词表全不命中 → 兜底「期望差(主观)」，不进质量根因统计，避免品控方向被口味偏好污染。

## 示例 4：整批归因与治理阈值

**输入**：`examples/input.json` 全量 12 条（果真甜生鲜旗舰店，拼多多，含 3 带图 2 追评）。

**输出**：加权总数 14；首要根因「期望差(主观)」36%；**质量安全类 14% > 10% → 当日处理**；每类根因自动带治理动作与数字目标。详见 `examples/output.md`。

*所有输出标注「AI 生成内容」；疑似恶意差评不进根因统计，转 dispute-evidence-pack-flow。*
