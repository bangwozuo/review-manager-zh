# 测试报告

## 资产形态

本技能为 T2 生成型（纯提示词），无脚本产物；验证方式为 prompt 深度校验 + 示例真实性与规范符合度人工核对。

## 校验记录（2026-09-30）

| 检查项 | 结果 |
|---|---|
| prompt 长度 ≥ 1200 字 | ✅（约 2400 字） |
| 含量化标准（30-80 字 / L1-L5 成本上限 / 2 小时介入） | ✅ |
| 含输出模板（回复文案表 / 根因判断 / 补救建议） | ✅ |
| 领域专属禁止项 ≥ 2 条 | ✅（模板腔 / 授权外补偿 / 未核实自认 / 诱导改评 / 公开缠辩） |
| examples/input.json 真实数据 | ✅（真实差评 + 授权口径） |
| examples/output.md 无占位符 | ✅（按 prompt 规范生成的完整方案） |

## 示例输出核对

| 项 | 期望 | 实测 | 结论 |
|---|---|---|---|
| 回复字数 | 30-80 字 | 77 字 ✅ | 通过 |
| 四件套结构 | 认领+原因+方案+通道 | 齐全 ✅ | 通过 |
| 补偿授权 | ≤ 20 元 | 15 元（授权内）✅ | 通过 |
| 根因判断 | 引原文给依据 | 引「物流慢了点，等了5天才到」✅ | 通过 |

## 边界用例

- policy 为空 → 只出文案不出补偿方案，并在存疑项标注
- 根因标签缺失 → 模型按原文判断并在「根因判断」表给依据
- 疑似恶意差评输入 → 不写安抚回复，输出转申诉路由说明
