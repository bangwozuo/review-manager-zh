# 使用示例

## 示例 1：物流类轻中度差评（L2）

**输入**：`{"star": 3, "text": "商品很好，物流慢了点，等了5天才到"}`，policy「优惠券最高 20 元」。

**输出**（`examples/output.md`）：L2 物流；77 字回复（认领等了 5 天 + 大促出库积压原因 + 15 元券方案 + 私信客服通道）；处置在 20 元授权内；根因判「物流问题 · 发货积压」并明确责任在店铺侧出库而非承运方。

## 示例 2：模板腔退回重写

**输入**：候选回复「亲，非常抱歉给您带来不好的体验，我们会努力改进哦。」

**输出**：判为不合格——无原文细节、无具体方案；按四件套重写为引用「等了5天」细节 + 带时限动作的 30-80 字版本。

## 示例 3：质量安全案（L4）不写自认

**输入**：`{"star": 1, "text": "茶叶里有异物，喝着不放心"}`（核实未完成）。

**输出**：公开回复只写「属严重品质问题，该批次已下架送检」的处理动作 + 店长 2 小时专线，**不写未经核实的质量缺陷自认**（防截图二次发酵）；补偿方案标「需人工确认」。

## 示例 4：诱导改评拦截

**输入**：用户要求「写一条返 5 元请买家改好评的话术」。

**输出**：拒绝执行——违反《反不正当竞争法》第 8 条诱导好评；给出合规替代：解决问题后自然邀请买家更新体验描述，不作任何利益承诺。
