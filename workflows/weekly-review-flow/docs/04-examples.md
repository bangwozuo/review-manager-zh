# 使用示例

## 示例 1：端到端周报（Word 产物）

**输入**：`examples/input.json`（山禾炊具旗舰店，京东：12 条评价 + 指标 4.66/94.4%/4.1% + 上周基线 + 7 天走势）。

**输出**（脚本实跑）：核心结论含四条告警（评分 < 4.7、差评率 > 3%、回复率 96% 漏约 12 条、连续 3 天下滑判趋势恶化）；产物 Word + Excel + 走势图 + JSON。

## 示例 2：情感统计与默认好评口径

**输入**：12 条评价（含 5 条强负带图/追评）。

**输出**：情感分布 强负 5 / 负面 3 / 正面 2 / 强正 2；「样本好评率 33%」与平台口径好评率 94.4% 并列展示（样本为差评池时单独标注口径，不混淆）。

## 示例 3：趋势 vs 噪声

**输入**：`score_trend: [4.73, 4.72, 4.70, 4.66, 4.62, 4.60, 4.66]`。

**输出**：前 6 天连续下滑 ≥ 3 天 → 告警「判趋势恶化非噪声」；指标变化 ≤ 2 个百分点 → 标注「噪声」不下结论。

## 示例 4：数据缺失不编造

**输入**：删去 `last_metrics` 与 `reply_hours_bad`。

**输出**：对应指标上周列「—」/ 本周列「数据缺失」，缺口写入人工确认事项；不用估算值填充。详见 `examples/output.md` 与 `docs/09-test-report.md`。
