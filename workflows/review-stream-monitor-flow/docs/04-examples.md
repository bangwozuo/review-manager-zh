# 使用示例

## 示例 1：P0 带图差评 + 涉诉词转人工

**输入**：`{"star": 1, "text": "奶瓶到手就裂了，还划到手，这种质量问题必须曝光", "has_image": true}`。

**输出**（脚本实跑）：P0（2 小时 SLA）；命中涉诉风险词「曝光」+ 人身安全 → **处置动作改为转人工+店长介入**，停用一切模板话术；留证原话与截图。

## 示例 2：追评差评自动升级

**输入**：`{"star": 1, "text": "宝宝用了红屁股…", "has_image": true, "is_followup": true}`。

**输出**：本为 P1（强负带图已是 P0）/ 追评无图强负 → P1 升 P0；本例命中「红屁股」安全类 → 转人工。

## 示例 3：好评回复队列

**输入**：`{"star": 5, "text": "第二瓶回购，防胀气设计真的好用…", "has_image": true}`。

**输出**：进入好评回复队列（24 小时内 30-80 字）；提示不诱导晒图返利（返现换图属诱导好评违规）。

## 示例 4：整日监控与告警

**输入**：`examples/input.json` 全量 8 条（晨光母婴旗舰店，天猫，2026-09-29）。

**输出**：P0×2 / P1×3 / P2×1 / 好评×2；告警「今日 P0 未清零：2 条带图差评须 2 小时内处置」；转人工 1 件；产物 Excel+Word+JSON。详见 `examples/output.md`。
